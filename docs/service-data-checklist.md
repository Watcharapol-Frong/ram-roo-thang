# ข้อมูลบริการ — สิ่งที่ต้องเก็บเพิ่ม

เอกสารนี้ใช้ติดตามงานเก็บข้อมูลขั้นตอนราชการที่บอทใช้ตอบคำถามนักศึกษา
ทุกอย่างในนี้ลงที่เดียวคือ `data/baseline-dataset.json` แล้ว `cd worker && npm run deploy`

> **เช็คความคืบหน้าเมื่อไหร่ก็ได้ด้วย `node scripts/service-data-report.mjs`**
> สคริปต์อ่านข้อมูลจริงผ่านโค้ดตัวเดียวกับที่บอทใช้ ไม่ต้องมาไล่ติ๊กในเอกสารนี้ด้วยมือ
> (ตารางในเอกสารนี้จึงไม่มี checkbox — ของจริงอยู่ที่สคริปต์เสมอ)

---

## ทำไมต้องเก็บ

24 ส.ค. 2026 มีนักศึกษาถามเรื่องขอใบเช็คเกรด บอทบอกที่ตั้งได้ถูก แต่พอถามต่อว่า
"ขอขั้นตอนการยื่น" กลับตอบว่า *"ยังไม่มีข้อมูลขั้นตอนในระบบ"* — ทั้งที่ข้อมูลมีครบ

ฝั่งโค้ดแก้ไปแล้ว (ดูหัวข้อ *Service questions* ใน README) ตอนนี้บอทตอบได้ทุกด้าน
**เท่าที่มีข้อมูล** ส่วนที่เหลือคือช่องว่างของข้อมูล ซึ่งเป็นงานในเอกสารนี้

ทุกครั้งที่บอทตอบไม่ได้ ระบบบันทึกคำถามนั้นไว้ ดูได้ที่

```bash
curl -H "x-admin-token: $ADMIN_TOKEN" https://<worker>/api/admin/unanswered
```

จัดกลุ่มตามความถี่มาให้แล้ว — ใช้เป็นตัวจัดลำดับงานได้ตรงกว่าการเดา

---

## ช่องที่ต้องกรอก

เพิ่มฟิลด์เหล่านี้เข้าไปใน service แต่ละตัว **ห้ามลบ `steps` เดิม** — ระบบใช้ฟิลด์ใหม่ก่อนเสมอ
และถ้ายังไม่มีฟิลด์ใหม่ก็ยังแกะจาก `steps` ไปพลางได้

| ฟิลด์ | ชนิด | ลำดับ | ตัวอย่าง | ทำไมต้องมี |
|---|---|:--:|---|---|
| `documents` | array | **P1** | `["บัตรนักศึกษา", "บัตรประชาชน"]` | เตรียมผิด = ไปถึงแล้วทำเรื่องไม่ได้ |
| `hours` | string | **P1** | `"จันทร์-ศุกร์ 08:30-16:30 น. (พักเที่ยง 12:00-13:00)"` | ไปถึงแล้วปิด คือความเสียหายที่หนักที่สุด |
| `fee` | string | P2 | `"ฉบับละ 50 บาท"` | ต้องรู้ว่าพกเงินไปเท่าไหร่ |
| `duration` | string | P2 | `"ปกติรับได้วันถัดไป / ด่วนภายในวันเดียว"` | วางแผนว่าต้องมากี่รอบ |
| `period` | string | P2 | `"กันยายน - ธันวาคม ของทุกปี"` | บางเรื่องเปิดรับเฉพาะบางเดือน พลาดแล้วรอปีหน้า |
| `contact` | string | P3 | `"02-310-8000 ต่อ 8614"` | ไว้ถามต่อเองเมื่อเกินขอบเขตบอท |
| `location` | string | — | `"อาคาร สวป. (KLB) ชั้น 1 ช่อง 4"` | มีอยู่แล้วใน `short_answer` เติมได้ถ้าอยากให้เจาะจงกว่า |
| `procedure` | array | — | `["ติดต่อ...", "กรอกแบบฟอร์ม..."]` | ครบแล้วทุกเรื่อง (แกะจาก `steps` อัตโนมัติ) |

### ตัวอย่างเต็ม

```jsonc
{
  "service_id": "TRANSCRIPT_REQUEST",
  "name": "ขอใบรับรองผลการเรียน (Transcript / ใบเช็คเกรด)",
  "aliases": ["ใบเช็คเกรด", "ทรานสคริปต์", "..."],
  "short_answer": "ติดต่อได้ที่อาคาร สวป. (KLB) ชั้น 1 ช่อง 4 ครับ",
  "building_id": "KLB",
  "steps": "1. ติดต่ออาคาร สวป. ...",          // ← ของเดิม เก็บไว้

  "documents": [                                // ← เพิ่ม
    "บัตรประจำตัวนักศึกษา",
    "บัตรประชาชน",
    "ใบเสร็จลงทะเบียนภาคล่าสุด"
  ],
  "hours": "จันทร์-ศุกร์ 08:30-16:30 น. (พักเที่ยง 12:00-13:00) ปิดเสาร์-อาทิตย์",
  "fee": "ฉบับละ 50 บาท",
  "duration": "ปกติรับได้วันถัดไป",
  "period": "ยื่นได้ตลอดปี",
  "contact": "02-310-8000 ต่อ 8614"
}
```

### กฎการเขียนที่ต้องรักษา

- **ห้ามเดา** ถ้าไม่แน่ใจให้เว้นว่างไว้ ระบบบอกว่า "ยังไม่มีข้อมูล" แล้วเสนอด้านอื่นแทนได้อยู่แล้ว
  ข้อมูลผิดแย่กว่าข้อมูลว่าง เพราะนักศึกษาเชื่อแล้วเดินทางไปจริง
- **หนึ่งรายการต่อหนึ่งบรรทัดใน `documents`** อย่ายัดหลายอย่างรวมกันด้วยลูกน้ำ
  บอทแสดงเป็นรายการทีละบรรทัดให้ตรวจตอนเตรียมของ
- **ระบุจำนวนชุด/ฉบับให้ชัดถ้ามีเงื่อนไข** เช่น `"สำเนาบัตรประชาชน 2 ชุด (เซ็นรับรองสำเนา)"`
- **`hours` ใส่วันหยุดด้วย** ถ้าปิดเสาร์-อาทิตย์หรือพักเที่ยงให้เขียนไว้ในประโยคเดียวกัน
- **`period` ใช้กับเรื่องที่มีหน้าต่างเวลาเท่านั้น** เรื่องที่ยื่นได้ตลอดให้ใส่ `"ยื่นได้ตลอดปี"`

## ลำดับงาน

**รอบที่ 1 (P1)** — `documents` ครบทั้ง 11 เรื่องแล้วจากรายงานวิเคราะห์ระบบงานทะเบียน (24 ส.ค. 2026)
เหลือ `hours` ของ 9 เรื่องที่ไม่ได้ทำที่ One Stop Service — เอกสารต้นทางระบุเวลาไว้เฉพาะเคาน์เตอร์ OSS
(จันทร์-ศุกร์ 08:30-16:00 น.) ที่ต้องไปถามเพิ่มคือเวลาทำการของ **อาคาร สวป. ชั้น 2** (ทะเบียนประวัติ),
**กองคลัง ตึกอธิการบดี ชั้น 1** และ **ฝ่ายทะเบียนของคณะ**

**รอบที่ 2 (P2)** — `fee` (เหลือ 5) · `duration` (เหลือ 9) · `period` (เหลือ 7)
ส่วนใหญ่อยู่ในสี่เรื่องที่รายงานไม่ได้ครอบคลุม: ผ่อนผันทหาร · ลงทะเบียนเรียน · ตารางสอบ · สอบซ้ำซ้อน

**รอบที่ 3 (P3)** — `contact` (เหลือ 12)

### บริการที่เพิ่มเข้ามาจากรายงาน (24 ส.ค. 2026)

`CHECK_GRADE` ใบตรวจสอบผลการเรียน · `FACULTY_TRANSFER` ย้ายคณะ/เปลี่ยนสาขา ·
`STUDY_SYSTEM_TRANSFER` โอนย้ายระบบการเรียน · `STATUS_MAINTENANCE` ค่ารักษาสถานภาพ

`STATUS_MAINTENANCE` ยังไม่มีตัวเลขค่าธรรมเนียม — รายงานเขียนแค่ว่า "ชำระค่ารักษาสถานภาพ" ไม่ได้ระบุจำนวน

**ต่อเนื่อง** — ดู `/api/admin/unanswered` ทุก 1-2 สัปดาห์ แล้วเติมตามที่คนถามจริง
ถ้าเห็นคำถามที่ควรตอบได้แต่ไม่ match แปลว่าต้องเพิ่ม `aliases` ไม่ใช่เพิ่มข้อมูล

## ส่งข้อมูลมายังไงก็ได้

ถ้าสะดวกทำเป็นตาราง/Google Sheet ให้ใช้คอลัมน์ตามนี้ เดี๋ยวแปลงเข้า JSON ให้

| service_id | เอกสารที่ต้องเตรียม | ค่าธรรมเนียม | เวลาทำการ | ระยะเวลาดำเนินการ | ช่วงเวลาที่เปิดรับ | เบอร์ติดต่อ |
|---|---|---|---|---|---|---|
| TRANSCRIPT_REQUEST | บัตรนักศึกษา<br>บัตรประชาชน | 50 บาท/ฉบับ | จ-ศ 08:30-16:30 | วันถัดไป | ตลอดปี | 02-310-8000 |

(ช่องเอกสารขึ้นบรรทัดใหม่ทีละรายการ)

## ตรวจงานก่อนปิด

```bash
node scripts/service-data-report.mjs     # ช่องไหนครบแล้วบ้าง
node scripts/validate-flex.mjs           # การ์ดที่บอทส่งยังถูกกฎ LINE
cd worker && npm run deploy              # ข้อมูลอยู่ใน bundle ต้อง deploy ใหม่ถึงจะมีผล
```

> ⚠️ ข้อมูลอ้างอิงถูก bundle เข้า worker ไม่ได้อยู่ใน KV แล้ว — **แก้ไฟล์อย่างเดียวไม่พอ ต้อง deploy**
> (เหตุผลอยู่ใน README หัวข้อ *Why reference data is bundled and not in KV*)
